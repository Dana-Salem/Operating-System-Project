# Performance Evaluation of CPU Scheduling Algorithms

This project evaluates and compares the performance of common CPU scheduling algorithms using C++.

## Project Overview

The project implements and analyzes five CPU scheduling algorithms using a unified dataset. The goal is to compare their behavior based on waiting time, turnaround time, fairness, responsiveness, and efficiency.

## Algorithms Implemented

- First-Come First-Served (FCFS)
- Round Robin (RR)
- Shortest Job First (SJF)
- Shortest Remaining Time First (SRTF)
- Priority Scheduling (Non-Preemptive)

## Main Features

- C++ implementation of CPU scheduling algorithms
- Calculation of waiting time and turnaround time
- Comparison between preemptive and non-preemptive algorithms

- C++
- Operating Systems Concepts
- CPU Scheduling
